# Вывод специализированных MCP-инструментов сопоставления сторон внутреннего перевода

**Статус:** Утверждено (2026-09-05, rev.4).

## Назначение

- Шесть специализированных инструментов MCP сопоставления сторон внутреннего перевода дублируют универсальные инструменты документов выравнивания и вызывают выведенный HTTP-ресурс.
- Нужна одна MCP-поверхность этого вида документа: универсальные инструменты документов выравнивания.

## Входит в объём

- Снятие с регистрации шести специализированных инструментов сопоставления сторон внутреннего перевода.
- Обновление справочника доступных инструментов MCP.

## Вне объёма

- Не входят модель данных, DDL и инварианты слоя сохранения (FIN-349).
- Не входит проектирование HTTP-контракта документов выравнивания (FIN-354).
- Не входит вывод HTTP-ресурса сопоставления сторон внутреннего перевода (FIN-379).
- Не входят изменение контракта универсальных инструментов документов выравнивания и добавление новых инструментов этого ресурса (FIN-355).
- Не входит пользовательский интерфейс сопоставления (FIN-352).
- Не входят инструменты погашения расхода (FIN-376).
- Не входит заглушка, псевдоним или перенаправление выведенного имени инструмента на универсальный инструмент.
- Не входит переходный период, в котором выведенные имена ещё успешны.
- Не входит автоматический подбор пар равных сумм в одной валюте (FIN-203).
- Не входит применение июльского сопоставления на операционном профиле (FOPS-40).

## Текущее поведение

| Область | Текущее поведение | Проблема |
| ------- | ----------------- | -------- |
| HTTP | Пути `/api/v1/internal-transfer-matches` выведены (FIN-379). Тип `internal_transfer` обслуживает `/api/v1/clearing-documents` (FIN-354) | Специализированные инструменты MCP вызывают выведенный ресурс |
| MCP | Шесть инструментов FIN-351 зарегистрированы рядом с двенадцатью инструментами FIN-355 | Две MCP-поверхности одного вида документа |
| MCP | FIN-355 уже создаёт, читает, перечисляет и удаляет тип `internal_transfer` | Специализированные имена не добавляют отдельной операции |

## Целевое поведение

#### Выведенные имена (D-01)

- Выведенные имена этой задачи есть `list_internal_transfer_matches`, `get_internal_transfer_match`, `create_internal_transfer_match`, `create_internal_transfer_matches`, `delete_internal_transfer_match` и `delete_internal_transfer_matches`.
- MCP-сервер не регистрирует ни одно выведенное имя.
- MCP-сервер не регистрирует заглушку, псевдоним, перечисление действия и перенаправление выведенного имени на инструмент FIN-355.
- MCP-сервер не вводит новое специализированное имя сопоставления сторон внутреннего перевода.
- Все операции MCP над документами типа `internal_transfer` выполняются только инструментами FIN-355.
- Это переопределяет FIN-351 D-01: шесть инструментов больше не являются контрактом MCP.
- Это переопределяет FIN-355 D-11 в части, где FIN-380 перенацеливает инструменты FIN-351: эта задача их выводит, а не перенацеливает. Контракт инструментов FIN-355 эта задача не изменяет.

#### Исход вызова выведенного имени (D-02)

- Вызов выведенного имени MCP-сервер обрабатывает так же, как вызов любого имени, которое MCP-сервер не регистрирует.
- MCP-сервер не разбирает аргументы выведенного имени.
- MCP-сервер не получает сессию API и не вызывает HTTP на вызове выведенного имени.
- MCP-сервер не задаёт отдельное тело ошибки выведенного имени сверх ошибки незарегистрированного имени сервера.
- MCP-сервер не возвращает на вызове выведенного имени код ошибки HTTP и не возвращает `error.code` API.
- Норма D-02 действует для каждого выведенного имени по отдельности и для любого набора аргументов, включая пустой объект.

#### Регистрация и справочник (D-03)

- Схемы и обработчики выведенных имён не регистрируются в `server.py`.
- Наблюдаемый контракт модуля `scripts/internal_transfer_matches.py` — недоступность его обработчиков как инструментов MCP. Наличие или отсутствие файла после снятия регистрации эта задача не нормирует.
- Справочник `mcp-gaps.md` не содержит ни одно выведенное имя.
- Справочник `mcp-gaps.md` сохраняет инструменты FIN-355, существовавшие на момент реализации этой задачи, без изменения смысла строк.
- После поставки метка `mcp-gap` снимается с FIN-380 при переводе задачи в Done и не входит в критерий функциональной приёмки.

#### Обратная совместимость (D-04)

- MCP-сервер допускает разрыв обратной совместимости с шестью инструментами FIN-351.
- Разрыв действует для каждого вызова выведенного имени после поставки этой задачи.
- MCP-сервер не сохраняет переходный период, в котором выведенные имена ещё успешны.
- Универсальные инструменты FIN-355 эта задача не изменяет.
- Прочие существующие инструменты MCP эта задача не изменяет.

#### Канал сопоставления через MCP (D-05)

- Создание, чтение, список, пакетное создание, удаление и пакетное удаление типа `internal_transfer` через MCP выполняются инструментами FIN-355 по контракту FIN-355.
- Эта задача не задаёт тела, фильтры, коды успеха HTTP, разворачивание ответа и классы ошибок обёртки FIN-355.
- На вызове выведенного имени MCP-сервер не вызывает HTTP, включая пути `/api/v1/internal-transfer-matches`, `/api/v1/internal-transfer-matches/batch` и `/api/v1/internal-transfer-matches/{match_id}`.

## Предположения, предусловия и ограничения

- Универсальные инструменты. На профиле прогона доступны инструменты FIN-355 по контракту FIN-355.
- HTTP-контракт документов выравнивания. На профиле прогона развёрнут HTTP-контракт FIN-354, включая ветвь `internal_transfer`.
- Выведенные HTTP-пути. На профиле прогона пути `/api/v1/internal-transfer-matches` не регистрируются согласно FIN-379.

## Критерий приёмки

#### Продуктовый результат

- Шесть специализированных имён сопоставления сторон внутреннего перевода отсутствуют в наборе инструментов MCP.
- Вызов каждого выведенного имени неотличим от вызова незарегистрированного имени; сессия API и HTTP не используются.
- Сопоставление сторон внутреннего перевода создаётся, читается, перечисляется и удаляется через универсальные инструменты документов выравнивания.
- Сценарий разновалютного сопоставления с несколькими позициями на стороне зачисления воспроизводится через MCP без выведенных имён и без выведенного HTTP-ресурса.
- Универсальные инструменты документов выравнивания сохраняют прежнюю семантику.

#### Контроль реализации

- Поведение, допускающее автоматизированную функциональную проверку, покрыто функциональными тестами.
- Автотесты проверяют отсутствие выведенных имён в регистрации и отсутствие получения сессии API и HTTP-вызова при попытке вызова каждого выведенного имени.
- Автотесты, которые проверяют регистрацию или успешный вызов выведенных инструментов FIN-351, удаляются либо актуализируются в соответствии с D-01. После изменения полный набор актуальных тестов каталога `tests/` не содержит ожиданий успешного вызова выведенных имён.
- Справочник доступных инструментов MCP не содержит выведенные имена и сохраняет инструменты FIN-355, существовавшие на момент реализации этой задачи.
